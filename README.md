# PPTGo

> 在思源笔记里浏览 PPTGo 的个人空间与团队文件，单击文件即可在页签中打开演示文稿。

这是参照 [博思白板（维护版）](https://github.com/Gt841/plugin-boardmix-maintained)
的交互方式，为 [PPTGo](https://pptgo.cn/) 编写的独立插件。

## 功能

- 目录树：个人空间 / 团队 → 项目 → 文件夹 / 文件。
- 单击文件夹、项目、团队名称即可展开或收起，无需点箭头。
- 单击文件名称直接在页签中打开演示文稿。
- 同一个文件只保留一个页签，重复点击时切换到已存在的页签。
- 页签使用 PPTGo 图标，便于和思源文档页签区分。
- 侧栏头部提供刷新、登录/登出按钮，始终显示并与标题对齐。
- 右键菜单支持新建演示文稿、新建文件夹、重命名、删除、移动、复制链接。
- 登录态保存在本地，刷新目录时优先读取已打开 PPTGo 页签中的最新 token。

## 安装

在 Release 中下载 `package.zip`，手动解压到 `工作空间/data/plugins/plugin-pptgo/`，
然后在「设置 → 集市 → 已下载」中启用。

## 使用

1. 打开左侧/右侧的「PPTGo」侧栏（dock）。
2. 未登录时点击登录图标，在页签中完成 PPTGo 登录，然后点击「我确认我已经登录了」。
3. 单击文件名称即可在页签中打开演示文稿；单击文件夹名称展开或收起目录。

> 退出登录会清除本机保存的 PPTGo 登录信息，需要重新登录才能使用目录树。

## 构建

```bash
npm install
npm run build   # 产物在 dist/ 与 package.zip
```
